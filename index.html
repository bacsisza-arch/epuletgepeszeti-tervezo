Gépész­tervkapcsolási vázlat
Válassz elemet a bal oldali tárból, vagy rajzolj vezetéket. 100% 0 ; 0

Hogyan használd?

Elem elhelyezése: kattints egy elemre a bal oldali tárban, majd kattints a rajzlapra. Shift-tel több példányt is lerakhatsz egymás után. Esc megszakítja.

Vezeték rajzolása: válaszd a Vezeték eszközt (L) és a színt (piros = fűtés előremenő, kék = visszatérő / hidegvíz, sárga = gáz, narancs = HMV, zöld = egyéb). Kattintgatással törésponttól töréspontig rajzolsz; az elemek csatlakozási pontjaira (kis körök) a vonal rátapad, és az elem mozgatásakor vele megy. Befejezés: dupla kattintás, Enter vagy jobb gomb. A 90° gomb a derékszögű vezetést kapcsolja.

Mozgatás, szerkesztés: Kijelölés eszközzel (V) húzd az elemeket. R forgat, Del töröl, Ctrl+D duplikál, dupla kattintással átnevezheted az elem feliratát vagy a szöveget. Kijelölt vezeték színe/vastagsága a fenti gombokkal módosítható.

Nézet: görgővel nagyítasz, üres területet húzva (vagy középső gombbal) mozgatod a rajzlapot.

Mentés: a rajz automatikusan mentődik a böngészőbe. A Mentés / Megnyitás gombokkal JSON fájlba írhatod ki, az SVG / PNG gombokkal képként exportálhatod.
